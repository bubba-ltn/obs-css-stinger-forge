How it works
  1. Install the OBS CSS Stinger Forge plugin in OBS once (see the plugin's README).
  2. Open this page from OBS (Tools > OBS CSS Stinger Forge), design a transition, name it and press Save as OBS transition.
  3. In OBS, open Scene Transitions, press + and pick Forge: your name. It then lives in the dropdown like any native transition, with no video file.
  4. The animation length is saved with the preset. Saving again under the same name updates it in OBS within a couple of seconds.
